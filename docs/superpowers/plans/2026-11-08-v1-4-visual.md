# v1.4 Visual Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aplicar o design escuro da v1.4 (heróis animados, home estilo capa, jogador com última partida em destaque, partida com cosméticos, dois modos de times e ordenação) sem perder o desempenho da v1.3.1.

**Architecture:** Tokens de cor/fonte no Tailwind + CSS vars (tema só escuro). Lógica nova em funções puras testadas (`lib/hero-art.ts`, `lib/player-summary.ts`, `lib/team-sort.ts`, cosméticos em `lib/opendota.ts`). Visual em componentes: `HeroRender` (vídeo com fallback, cliente) e `HeroBanner` (cabeçalho com ilustração + herói), reutilizados nas três telas.

**Tech Stack:** Next 16 (`cacheComponents`), React 19, Tailwind v3, shadcn/ui, Vitest 5, Supabase (sem mudança de schema).

**Spec:** `docs/superpowers/specs/2026-11-08-v1-4-visual-design.md`

## Global Constraints

- Tema **só escuro**; sem `next-themes`, sem seletor de tema.
- Cores: fundo `#0b0d10`; painel `#12151a`; borda `#23262c`; texto `#f2efe8`; secundário `#a39e93`; brasa `#e4572e`; vitória `#5bbf7f`; derrota `#e0596a`; lado (texto neutro) `#d8d3c8`.
- Raridades: common `#b0c3d9`, uncommon `#5e98d9`, rare `#4b69ff`, mythical `#8847ff`, legendary `#d32ce6`, immortal `#e4ae39`, arcana `#ade55c`, ancient `#eb4b4b`.
- Fontes: títulos Barlow Condensed 600/700 maiúsculas; texto Inter (`next/font/google`).
- Lado Radiant/Dire sempre em texto neutro, nunca verde/vermelho.
- Rodapé em todas as páginas: `Projeto de fã, não afiliado à Valve.`
- Animação: `https://cdn.cloudflare.steamstatic.com/apps/dota2/videos/dota_react/heroes/renders/<key>.webm`; ilustração: `https://cdn.cloudflare.steamstatic.com/apps/dota2/images/dota_react/home/radiant_dire5.jpg`, `brightness(.28)`, fixa.
- Vídeo nunca bloqueia o render; imagem estática primeiro; `prefers-reduced-motion` → só estática; animação presa no bloco (`overflow:hidden`) com `mask-image: linear-gradient(180deg,#000 62%,transparent 92%)`.
- OpenDota só no servidor; páginas leem via `lib/data.ts`. `npm test`, `npm run lint`, `npx tsc --noEmit`, `npm run build` passam ao fim de cada tarefa.
- Textos de interface em português.

## Review Focus

- Herói sem `.webm` no CDN (404, herói novo) → fica a imagem estática, sem ícone quebrado. Coberto na Task 2 (verificação no navegador com chave inexistente).
- Herói fora da lista (`heroes[id]` ausente) → sem animação, texto `hero_id N`, cabeçalho continua de pé. Teste `heroKey` com entrada ausente na Task 2; `mostPlayed` com herói desconhecido na Task 4.
- Partida com `radiant_win === null` → resultado "—", não conta como vitória nem derrota no "mais jogado". Teste na Task 4.
- Valores `null` em colunas ordenáveis (`net_worth`, `hero_damage`, `tower_damage`) → sempre no fim, nos dois sentidos. Teste na Task 6.
- `detail` salvo na versão 1 (sem cosméticos) → rebuscado uma vez; cosmético sem `image_path`/raridade → `img: null`/`"common"`. Testes na Task 5.
